# Number-Notation-With-Words
This repository contains code that makes numbers much more overviewable. For example, "1,234,000,000,000,000,000,000" is converted to "1.234 sextillion".<br>
Go to [https://jonanfoxje.github.io/number-notation-with-words](https://jonanfoxje.github.io/number-notation-with-words) to test it.

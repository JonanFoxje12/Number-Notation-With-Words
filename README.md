# Number-Notation-With-Words
This repository contains code that makes numbers much more overviewable. For example, "1_234_000_000_000_000_000_000" is converted to "1.234 sextillion".<br>
Go to [https://jonanfoxje12.github.io/Number-Notation-With-Words/](https://jonanfoxje12.github.io/Number-Notation-With-Words/) to test it.
